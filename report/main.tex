Sets:

The set of soil types
\begin{equation}
\label{eq:1}
\mathcal{S} = \big\{ \text{deep loam}, \text{silt loam}, \text{sandy loam}, \text{heavy clay} \big\}.
\end{equation}

The set of blocks
\begin{equation}
\label{eq:7}
\mathcal{B} = \left\{ B_i | 0 < i \leq N \right\},
\end{equation}
with $N=4$ for this problem. To each block $b \in \mathcal{B}$ is associated a soil type $\sigma(b) \in \mathcal{S}$.

The set of crops
\begin{equation}
  \label{eq:2}
  \begin{align}
    \mathcal{C} = \big\{& \text{winter wheat}, \text{winter barley}, \text{grain maize},\\
    &\text{sugar beet}, \text{potato}, \text{field beans}, \text{cover fallow} \big\}.
  \end{align}
\end{equation}
